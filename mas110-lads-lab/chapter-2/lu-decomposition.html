Concept primer

Know these ideas before running the code

Rank bottleneck

rank(AB) ≤ k

If an m×k matrix multiplies a k×n matrix, the product can carry at most k independent directions.

Watch for: The construction guarantees rank at most k; random factors usually—but not logically always—reach k.

Pivoted LU

A = P L U

SciPy factors a matrix into a row permutation, a lower-triangular factor, and an upper-trapezoidal factor.

Watch for: With Q=Pᵀ, the equivalent identity is QA=LU.

Residual

R = QA − LU

Subtracting the reconstructed matrix from the target matrix reveals numerical disagreement entry by entry.

Watch for: Floating-point residuals are expected to be tiny, not symbolically zero.

Numerical rank

rank(U) = k

Matrix rank is estimated from singular values relative to a tolerance determined by scale and precision.

Watch for: L is 10×10 with unit diagonal and rank 10; it is not rank k in this experiment.
