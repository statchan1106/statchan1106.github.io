Concept primer

Know these ideas before running the code

Pivot

aᵣⱼ

The pivot is the active nonzero entry used to eliminate values below it.

Watch for: The active pivot row r may differ from the current column j if a column is skipped.

Partial pivoting

arg maxᵢ≥ᵣ |aᵢⱼ|

Choose the largest absolute entry in the active column among rows not yet processed.

Watch for: Absolute magnitude, not signed value, determines the winner.

Multiplier

u = aₖⱼ / aᵣⱼ

The target divided by the pivot gives the amount of pivot row to subtract.

Watch for: The elimination matrix stores −u, while the usual LU lower factor stores the inverse operation.

Tolerance

|pivot| < ε

A small threshold treats numerically tiny values as zero and avoids unstable division.

Watch for: A skipped column does not advance the active pivot row.
